## ✨ What is TripCraft?

Planning a trip usually involves messy spreadsheets, endless browser tabs, scattered booking links, and complex budgeting. **TripCraft** eliminates this friction by instantly creating highly structured and realistic travel schedules. 

Whether you are planning a spiritual journey to Makkah and Madina, an adventurous trek in the Hunza Valley, or a luxury vacation in Paris, TripCraft provides a complete day-by-day itinerary with an accurate, itemized budget breakdown in mere seconds.

### 🎯 Core Features
* **🌍 Interactive 3D Spatial Globe:** Spin, pan, and select destinations directly from a highly responsive 3D globe.
* **⚡ Automated Itineraries:** Generates smart, structured, and realistic day-by-day travel schedules instantly.
* **📍 Curated Destinations:** Pre-optimized routes and coordinate telemetry for global hubs like Tokyo, Dubai, Paris, Hunza, Makkah, and Madina.
* **💰 Smart Algorithmic Budgeting:** Accurate, itemized cost breakdowns categorized by Lodging, Food, Travel, and Leisure, intelligently mapped to local currencies (PKR, SAR, EUR, etc.).

## 🛠️ System Architecture & Tech Stack

Our platform is built on a modern, edge-ready architecture to ensure low latency and high scalability:

* **Frontend:** Next.js 14 (App Router) with React & TypeScript.
* **Styling:** Tailwind CSS for a fully responsive, utility-first design.
* **3D Rendering:** Three.js & React Three Fiber for the interactive globe canvas.
* **Smart Engine:** Integrated with Gemini SDK for data structuring and route generation.
* **Data Validation:** Zod for strict backend schema validation.
* **Auth & Database:** Supabase (PostgreSQL).
* **Deployment:** Vercel edge network.
